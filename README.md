# remotion (phoenyx-video)

Projeto em **Remotion** para criar/renderizar um vídeo promocional da **Phoenyx (consultoria TOTVS Protheus)**.

## Dor que resolve

Permite produzir vídeo com controle de código (componentes React), facilitando ajustes, versionamento e geração consistente de renders.

## Stack

- Remotion
- React
- TypeScript

## Como rodar

```bash
npm install
npm run start   # abre o Remotion Studio
```

## Render

```bash
npm run render
```
